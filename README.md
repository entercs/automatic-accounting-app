# 记账助手

自动监听微信、支付宝、京东、美团等支付通知，支付成功后自动记录交易，无需手动输入。

## 安装

下载 APK 文件并安装到手机（Android 8.0 及以上）。

## 首次使用

### 1. 开启通知读取（推荐）

打开应用 → “我的” → “自动记账” → “开启通知读取”，在系统通知使用权设置中允许记账助手读取通知。返回应用确认显示“已连接”。

### 2. 按需开启屏幕补充

在“屏幕识别 · 可选补充”中进入无障碍设置。此通道用于补充识别支持的支付成功页面；未开启时通知读取仍可工作。

### 3. 开始记账与检查漏记

开启支付 App 自身的交易通知。完成支付后检查账单；在“识别记录”中查看成功、待补充或重复跳过的结果。无法识别的样本可以复制给开发者补充规则，也可以先手动补记。识别样本仅保存在本机，支持清空。

## 支持的支付场景

| App | 说明 |
|-----|------|
| 微信支付 | 支付成功/收款通知 |
| 支付宝 | 扫码支付、付款、免密自动扣款 |
| 京东 | 订单支付通知 |
| 美团 | 外卖等支付通知 |
| 银行卡 | 动账通知 |

## 手动记账

在首页点击"+"按钮，可输入金额、选择分类、添加备注。计算器键盘支持表达式输入（如 `12+5`）。

## 常见问题

**无障碍服务在哪里开启？**
应用内"我的"页面 → "通知监听"，或手机设置 → 无障碍 → 记账助手。

**为什么没有自动记录？**
1. 在“我的”确认通知读取显示“已连接”；已授权但未连接时尝试恢复或重新授权
2. 确认支付 App 确实发出了包含交易信息的新通知
3. 查看识别记录；无通知、隐藏金额、普通短信或未覆盖的模板需要手动补记

**记录了重复的账单怎么办？**
应用有自动去重机制，如仍出现重复，可能是多个应用同时监听通知导致。

## 数据安全

所有数据存储在本地设备，不会上传至任何服务器。
