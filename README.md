# 记账助手

一款 Android 自动记账应用，通过无障碍服务自动监听微信、支付宝、京东、美团等主流支付App的通知，在支付成功后自动记录交易，无需手动输入。

## 功能特性

### 自动记账
- 支付成功后自动记录，识别商户、金额、类型
- 支持微信支付、支付宝、京东、美团、银行卡通知
- 智能金额提取，自动过滤礼金、优惠券等干扰信息

### 手动记账
- 自定义计算器键盘，支持表达式输入（如 `12+5`）
- "再记"功能快速连续记账
- 支持语音输入金额

### 资产管理
- 多账户管理（微信、支付宝、京东、银行卡）
- 净资产自动汇总计算
- 月度统计，分类支出/收入饼图

### 数据导出
- CSV格式导出
- 支持分享到其他应用

## 权限说明

本应用需要以下权限：

| 权限 | 用途 |
|------|------|
| `android.permission.POST_NOTIFICATIONS` | 发送记账成功通知 |
| 无障碍服务 | 监听支付通知、自动提取金额 |

**无障碍服务是核心功能**，应用需要此权限来监听其他App的支付通知并自动记录。请在应用内或系统设置中开启。

## 使用步骤

### 1. 安装应用
下载 APK 并安装到 Android 设备（Android 7.0+）

### 2. 开启无障碍服务
1. 打开应用，进入"我的"页面
2. 点击"通知监听"开关
3. 系统会跳转至无障碍设置页面，找到"记账助手"并开启

### 3. 授予通知权限
确保应用可以读取其他App的通知（非通知屏蔽权限）

### 4. 开始使用
在支持的App完成支付后，应用会自动记录交易并发送通知

## 支持的支付场景

| App | 通知类型 | 支持状态 |
|-----|---------|---------|
| 微信支付 | 支付成功/收款 | ✅ |
| 支付宝 | 扫码支付、付款、免密支付 | ✅ |
| 京东 | 订单支付 | ✅ |
| 美团 | 外卖等支付通知 | ✅ |
| 银行卡 | 动账通知 | ✅ |
| 银行App（屏幕） | App内支付 | ⚠️ 部分不支持 |

> 注：部分银行App有安全管控，屏幕内容读取受限，但仍可处理通知栏消息。

## 常见问题

**Q: 为什么没有自动记录？**
- 检查无障碍服务是否已开启
- 检查通知权限是否正常授予
- 确认支付通知是否来自支持的App

**Q: 金额提取错误？**
- 京东的"叠加礼金"等优惠信息会被自动过滤
- 如遇特殊情况，可在交易记录中手动修改

**Q: 记录重复？**
- 检查通知权限是否被多个记账类应用同时使用
- 应用内有去重机制，短时间内的相同通知不会重复记录

本应用所有数据均存储在本地设备，不会上传至任何服务器。无障碍服务仅用于监听支付通知，不会读取其他敏感信息。
