# 记账助手

自动监听微信、支付宝、京东、美团等支付通知，支付成功后自动记录交易，无需手动输入。

## 安装

下载 APK 文件并安装到手机（Android 7.0 及以上）。

## 首次使用

### 1. 开启无障碍服务（关键步骤）

1. 打开应用 → "我的"页面 → "通知监听"
2. 点击开关，系统会跳转至无障碍设置
3. 找到"记账助手"并开启

> **必须开启无障碍服务才能使用自动记账功能。**

### 2. 授予通知权限

在系统设置中，确保应用可以读取通知（不要开启通知屏蔽）。

### 3. 开始使用

在支持的 App 完成支付后，应用会自动记录并发送通知。

## 支持的支付场景

| App | 说明 |
|-----|------|
| 微信支付 | 支付成功/收款通知 |
| 支付宝 | 扫码支付、付款、免密自动扣款 |
| 京东 | 订单支付通知 |
| 美团 | 外卖等支付通知 |
| 银行卡 | 动账通知 |

## 手动记账

在首页点击"+"按钮，可输入金额、选择分类、添加备注。计算器键盘支持表达式输入（如 `12+5`）。

## 常见问题

**无障碍服务在哪里开启？**
应用内"我的"页面 → "通知监听"，或手机设置 → 无障碍 → 记账助手。

**为什么没有自动记录？**
1. 确认无障碍服务已开启
2. 确认通知权限正常
3. 确认支付来自支持的 App

**记录了重复的账单怎么办？**
应用有自动去重机制，如仍出现重复，可能是多个应用同时监听通知导致。

## 数据安全

所有数据存储在本地设备，不会上传至任何服务器。
